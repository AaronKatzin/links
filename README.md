# Aaron Katzin

Personal link page for [aaronkatzin.com](https://aaronkatzin.com): a photo, a name, and links for WhatsApp, email, LinkedIn, and GitHub.

Plain static files (`index.html`, `style.css`, and images), published with GitHub Pages. No build step.

## Preview locally

```bash
python3 -m http.server
```

Open the URL the server prints.
